# 🎴 Quick Reference Flashcards

> Condensed one-liner summaries of key concepts from each lecture. Use for rapid review and exam preparation.

## Pre-Litigation

| Topic                | Key Point                                                                                 |
| -------------------- | ----------------------------------------------------------------------------------------- |
| **L01 - Interview**  | 7 stages: Preparation → Introduction → Listening → Questioning → Summary → Advice → Close |
| **L02 - Advice**     | Communicate uncertainty honestly. Client makes decisions; advise on options and risks.    |
| **L03 - ADR**        | Negotiation (party-led), Mediation (neutral facilitator), Arbitration (binding decision). |
| **L04 - Pre-action** | Letter of demand interrupts prescription, sets out claim, invites settlement.             |

## Pleadings

| Topic                        | Key Point                                                                               |
| ---------------------------- | --------------------------------------------------------------------------------------- |
| **L05 - Pleadings**          | *Facta probanda* (must prove) → plead. *Facta probantia* (means of proof) → evidence.   |
| **L06 - Statement of Claim** | Material facts only. No witness names, no evidence, no legal argument.                  |
| **L07 - Pleas**              | Admit, deny, or decline to admit. Special pleas = procedural bars (prescription, etc.). |
| **L08 - Replication**        | Confession and avoidance. Closes pleadings, sets stage for trial.                       |
| **L09 - Exceptions**         | Rule 23. No cause of action (law) or vague/embarrassing (fact). No evidence led.        |

| Topic                       | Key Point                                                                                |

## Trial Advocacy

| Topic                          | Key Point                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------ |
| **L15 - Courtroom Protocol**   | "Your Lordship" (High Court judge), "Your Worship" (magistrate). Robe in High Court. |
| **L16 - Opening Statement**    | Tell the story. No argument. Theme + theory. Roadmap of evidence. Short and clear.   |
| **L17 - Examination-in-Chief** | Open questions only. No leading. Refresh memory if needed. Prove documents properly. |
| **L18 - Cross-Examination**    | Leading questions. 4 techniques: Confront, Probe, Suggest, Undermine. Put your case. |
| **L19 - Re-Examination**       | Explain damage from cross. No new evidence (except with leave).                      |
| **L20 - Special Procedures**   | Proving documents, identification evidence, refreshing memory, formal admissions.    |
| **L21 - Closing Argument**     | Summarise evidence. Apply law. Deal with adverse facts. What relief? Stop when done. |

## Essential Mnemonics

### Proof-Making Model (8 Stages)

1. **A**rea of law
2. **C**ause of action/defence
3. **L**egal elements
4. **P**ropositions of fact
5. **E**vidence for each
6. **A**dmissibility/sufficiency
7. **T**heory of the case
8. **T**actics/strategy

### Cross-Examination Techniques

- **C**onfrontation — face facts
- **P**robing — extract admissions
- **S**uggestion — put your spin
- **U**ndermining — attack credibility

### Theory of the Case Test

- **C**omprehensive — all facts addressed
- **C**oherent — logical story
- **C**redible — judge will accept
- **L**egally sufficient — leads to result
