# Litigation Skills for South African Lawyers — Study Vault

An interlinked Obsidian vault generated from Chris Marnewick SC's *Litigation Skills for South African Lawyers*. It contains atomic **term** notes, structured **legal test/rule** notes (our adapted formulas), full teaching-walkthrough **lecture** notes, **MOC** indexes, and interactive diagrams/animations.

## How to use

1. Open this folder as a vault in [Obsidian](https://obsidian.md) (File → Open folder as vault → select the `vault` directory).
2. Start at **[[Home]]** for the map, or **[[All Lectures]]** to read in chapter order.
3. Hover any `[[link]]` to preview the note (hover previews are pre-enabled).
4. Open **Graph view** to see how concepts connect.

## Recommended community plugins (optional)

Install from Settings → Community plugins. The vault works without them; these just light up extra features:

- **Dataview** (`blacksmithgu`) — powers the live tables in the index notes (without it, those blocks show as plain code; the static link lists still work).
