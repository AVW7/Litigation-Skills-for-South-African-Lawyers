## 🎯 Study Pathways

### For Beginners
**Recommended sequence:**

1. Start with [[L00 - Introduction & Prefaces]] for orientation
2. Read [[L01 - Interviewing clients and witnesses]] and study the [[diagrams/interview-process-flow.html|interview process diagram]]
3. Work through pleadings sequence (L05 → L06 → L07)
4. Study the [[diagrams/litigation-timeline.html|complete litigation timeline]]
5. Proceed to trial advocacy (L15 → L16 → L17 → L18)

### For Exam Preparation
**Focus areas:**

1. **Pleadings** (L05-L09): Critical for drafting questions
2. **Trial advocacy** (L17-L18): Examination technique is heavily tested
3. **Fact analysis** (L14): Theory of the case fundamentals
4. Use diagrams as quick-reference visual summaries

### For Practical Reference
**Quick lookups:**

- Interview checklist → [[L01 - Interviewing clients and witnesses]] + [[diagrams/interview-process-flow.html]]
- Pleading structure → [[diagrams/pleadings-structure.html]] + L05

- Case procedure → [[diagrams/litigation-timeline.html]]
